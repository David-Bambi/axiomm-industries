# Axiomm Industries

Jeu de gestion d'une **industrie galactique** pour Android, fait avec **Godot 4.5**.
Le joueur dirige Axiomm : extraire, transformer, transporter et vendre à l'échelle
d'une galaxie. La vue s'inspire d'*Idle Planet Miner* ; la profondeur des chaînes de
production, de *Satisfactory*.

## État

Version **0.2.0** en cours : définir le jeu, avant tout code.

## Documentation

Fiches Concept (`.cpt`, du Markdown avec un en-tête YAML) : la racine
[`axiomm-industries.cpt`](axiomm-industries.cpt), puis [`docs/`](docs) : pitch,
joueur, boucle de jeu, économie, style, univers, technique, publication, feuille
de route. Prototype de l'économie : [`docs/prototype/economie.ods`](docs/prototype/economie.ods).
Maquettes : [`docs/maquettes/`](docs/maquettes).
